# Teksilo UI: parity with the Iced UI

This file maps every behaviour of the Iced UI (`src/gui/`) to where the Teksilo UI
(`src/teksilo_ui/`) provides it, and to the test or probe that checks it. It is the checklist the
final review works through: a row with no Teksilo location and no check means parity is not
done.

Rows come from three sources:
- every variant of the Iced `Message` enum (`src/gui/app.rs`) and of `AudioCenterMessage`
  (`src/gui/audio_center.rs`);
- every interactive element of the Iced views;
- every persistence key.

Status markers:
- **Variants not ported:** dead `Message` variants (handled but never emitted) are listed with
  status `dead`.
- **Stubs:** see [`teksilo-port-stubs.md`](teksilo-port-stubs.md). They are listed with status
  `stub`.
- **Behaviour changes:** see [`teksilo-port-quirk-fixes.md`](teksilo-port-quirk-fixes.md). They
  are listed with status `fixed #N`.

Every table below uses the same columns: `Iced | Behaviour | Teksilo | Check | Status`.

## How to read it

- **Iced** paths are relative to `src/gui/` (`app.rs:1695` is `src/gui/app.rs:1695`). A variant is
  written `Message::Name` or `AudioCenterMessage::Name`; the line numbers are its handler and the
  places that build it. Several near-identical variants may share a row when the cell names them all.
- **Teksilo** paths are relative to `src/teksilo_ui/` unless they start with `src/`.
- **Check** is a test as `module::path::tests::name` (the module path starts at the crate root, so
  `teksilo_ui::…`, `frontend::…` or `logic::…`), `module::tests::{a, b}` for several, or `probe:`
  followed by what a live probe (Wave F) must do, or a dash. `tools/check_parity.py` checks that every
  named test exists.
- **Status**: `ported`; `fixed #N` (a quirk fix, the number of its entry in the quirk-fix document);
  `stub` (kept as an Iced stub, in the stubs document); `dead` (a variant the Iced UI handles but
  never builds: the evidence is in the "Dead variants" section); `deviation` (a framework-imposed or
  otherwise deliberate difference: see "Deviations" at the end); `pending` (being implemented in
  `src/teksilo_ui/app/` when this document was written, filled at merge); `GAP` (no Teksilo
  counterpart found: see "Gaps" at the end).

Run `python3 tools/check_parity.py` after editing this file: it fails when a `Message` or
`AudioCenterMessage` variant has no row, a named test does not exist, a `fixed #N` has no entry in
the quirk-fix document, a status is not one of the values above, or a settings key is missing from
the persistence table.

it does. The Iced timers become facade events: the playback monitor thread (`frontend/monitor.rs`)
publishes the diffs and runs the housekeeping, and the view-models react to the events.
